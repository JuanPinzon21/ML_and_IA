# ML_and_IA
1. Aprendizaje supervisado (Supervised Learning)

Definición: El modelo aprende a partir de datos de entrada etiquetados (se conoce la respuesta correcta).

Objetivo: Predecir un valor o clasificar datos nuevos basándose en ejemplos previos.

Ejemplos:

Predecir el precio de una casa según su tamaño y ubicación.

Clasificar correos como “spam” o “no spam”.

2. Aprendizaje no supervisado (Unsupervised Learning)

Definición: El modelo trabaja con datos no etiquetados (no se conoce la respuesta), buscando patrones o agrupamientos.

Objetivo: Descubrir estructuras ocultas o relaciones en los datos.

Ejemplos:

Agrupar clientes según su comportamiento de compra (segmentación de mercado).

Detectar patrones en datos de transacciones bancarias para identificar fraude.

3. Aprendizaje por refuerzo (Reinforcement Learning)

Definición: El modelo aprende mediante prueba y error, recibiendo recompensas o penalizaciones según sus acciones.

Objetivo: Encontrar la mejor estrategia para maximizar una recompensa a largo plazo.

Ejemplos:

Un robot que aprende a caminar evitando obstáculos.

Un programa que juega ajedrez y mejora con cada partida.
